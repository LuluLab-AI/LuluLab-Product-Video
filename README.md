# LuluLab-Product-Video

Create 1–10 original UGC or story-driven product videos from product images. Video prompts always come from the private workflow. Configure video type, optional custom creative requirements, spoken language, Seedance model, duration, quantity, and creator reference (AI-generated by default or supplied by the user). Product identification includes name, visible selling points, market, and audience; market is identified with the product rather than listed as a generation setting. This Agent Skill uses the bundled LuluLab Node.js CLI for prompts, creator references, and video generation, with sequential segments, final assembly, saved task IDs, and up to three independent video workflows at once.

## How it works

1. The agent identifies the product name, visible selling points, market, and audience. It shows every configurable option in a table: video type, custom creative requirements, spoken language, model, duration, quantity, and creator reference. Prompts always use the private workflow. Cost disclosure appears outside the table, followed by a single confirmation before paid submission.
2. The bundled CLI submits each video's four-field request to the private SalesVideoPromptV2 workflow. The returned prompts are validated locally.
3. If the user has not supplied a creator image, LuluLab ImageGenV2 makes a multi-view creator and product reference from all product images.
4. LuluLab VideoGenV2 is the default video path. Before any video submission, an unavailable or unsupported LuluLab configuration may fall back to a verified LibTV, Xiaoyunque, then Dreamina CLI. A submitted task stays with its original provider and task ID.
5. Segments are generated in order and joined into a separate final video for each request.

The private creative workflow and its core metaprompts are not included in this public repository. SalesVideoPromptV2 must be deployed and mapped in the LuluLab task dispatcher before prompt generation can work.

## Install

Copy this entire repository into your agent's Skills directory as LuluLab-Product-Video, keeping SKILL.md, scripts, core, references, and agents together. Reload the agent's skill list. Codex and other agents may use different Skills directories.

Requirements: Node.js 20+, Python 3.10+, and FFmpeg for joining segments. Configure a LuluLab API key locally for paid tasks. The skill reads existing credentials and checks credits only before its first LuluLab paid submission; never put credentials in prompts, task files, logs, or this repository. Optional video providers need their own installed and authenticated CLIs.

## Use

Ask the agent: “Use $LuluLab-Product-Video with these product photos to make one 15-second UGC video for the US market.”

Defaults are original UGC, no custom creative requirements, US market, English speech, Seedance 2.0 Fast, 15 seconds, one video, and an AI creator reference. Users can choose a story-driven ad, add creative requirements that become part of the workflow metaprompt, specify a market or spoken language, select another supported model, change duration or quantity, or provide their own creator image. Prompts are always generated by the workflow. Prompt, image, and video tasks may consume credits. Paid retries or a change of paid model or provider require fresh authorization.
